# Manoj — Creative Developer Portfolio

A responsive React + Vite portfolio with a dark navy/orange design, animated sections, project cards, and a contact form.

## Run locally

```bash
npm install
npm run dev
```

In PowerShell, if script execution blocks `npm.ps1`, use `npm.cmd install` and `npm.cmd run dev` instead.

## Enable contact form email delivery

Follow [`CONTACT_FORM_SETUP.md`](./CONTACT_FORM_SETUP.md). The form uses EmailJS and needs your own Service ID, Template ID, and Public Key in a local `.env.local` file before it can deliver messages.
